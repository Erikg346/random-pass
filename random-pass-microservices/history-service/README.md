# History Service

This service is responsible for managing the history of password generation events. It logs each password generated by the password API and allows retrieval of this history.

## Features

- Log password generation events
- Retrieve password generation history
- Integration with other microservices for a cohesive architecture

## Setup Instructions

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd random-pass-microservices/history-service
   ```

2. **Install dependencies**:
   Ensure you have Python and pip installed, then run:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the service**:
   You can start the service by running:
   ```bash
   python src/app.py
   ```

4. **Access the API**:
   The service will be available at `http://localhost:5000`. You can use tools like Postman or curl to interact with the API.

## API Endpoints

- **POST /history**: Log a new password generation event.
- **GET /history**: Retrieve the list of password generation events.

## Observability

This service is integrated with OpenTelemetry for monitoring and tracing. Ensure that the observability tools are set up as per the project's documentation.
